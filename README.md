# Westland Chat

Клиентский ASI-плагин для SA-MP с интерфейсом чата на Dear ImGui. В проект также включена отрисовка игровых текстовых меток через Direct3D 9.

## Технологии

C++, Dear ImGui, Direct3D 9, хуки клиента SA-MP и SAMP-API.

## Подготовка и сборка

```bash
git clone --recurse-submodules https://github.com/STYOP2122/westland_chat.git
cd westland_chat
```

1. Установите Visual Studio с инструментами C++ v145 и Windows SDK либо перенастройте набор инструментов проекта.
2. Подготовьте зависимости `kthook` и `SAMP-API`: проект ссылается на `../deps/` относительно корня репозитория. Пути указаны в настройках include-каталогов проекта.
3. Откройте `Chat ImGui.sln` и выберите **Release / Win32**.
4. Соберите решение. Результат помещается в `build/` с расширением `.asi`.

Внешние зависимости из `deps/` не включены в этот репозиторий; одного клонирования недостаточно для сборки. Совместимость хуков зависит от версии клиента SA-MP.

## Структура

- `Chat ImGui/ChatImGui.cpp` и `.h` — интерфейс чата.
- `Chat ImGui/main.cpp` — точка входа.
- `Chat ImGui/labels/` — отрисовка меток и хуки.
- `Chat ImGui/libs/` — библиотеки интерфейса и работы с клиентом.
- `.gitmodules` — дополнительные зависимости ImGui и FreeType.

Для установки собранного плагина нужен ASI Loader.
